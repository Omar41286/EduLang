# EduLang – Plataforma de Gestión Académica de Idiomas

Sistema web Full Stack diseñado para automatizar y optimizar los procesos administrativos y académicos del Instituto Tecnologico de Leon de enseñanza de idiomas, incluyendo inscripciones, historial de alumnos y foros interactivos.

## Funcionalidades
 **Gestión de Alumnos y Kardex:** Control de expedientes, calificaciones e historial académico.
 **Examen de Colocación (Placement Test):** Módulo interactivo para evaluar el nivel de ingreso de los estudiantes.
 **Foros de Discusión:** Espacio comunitario integrado para resolución de dudas y respuestas entre alumnos y docentes.
 **Roles de Usuario:** Paneles diferenciados para alumnos y administradores.

## Tecnologías utilizadas
 **Frontend:** HTML5, CSS3, JavaScript (con estilos personalizados por módulo).
 **Backend:** PHP.
 **Base de datos:** MySQL (`Edulangxd.sql`).

## Cómo ejecutar localmente
1. Importa el archivo de base de datos `Edulangxd.sql` en tu gestor de MySQL local.
2. Configura los parámetros de conexión en el archivo `conexion.php`.
3. Despliega la carpeta en tu servidor local (por ejemplo, XAMPP en la carpeta `htdocs`).
